# PawCare — Design System

## 1. Design Goal
PawCare should look like a real local pet-care business website.

The design must feel:
- trustworthy
- warm
- clean
- professional
- approachable
- practical

It should not look like a generic AI-generated "modern landing page."

## 2. Visual Philosophy
Use restraint.

Every visual element should have a reason to exist. The interface should communicate the business first and decorate second.

### Avoid
- excessive gradients
- neon colors
- random blobs
- floating geometric shapes
- excessive glassmorphism
- excessive shadows
- excessive rounded containers
- oversized typography used only for visual impact
- unnecessary animations
- too many colors
- decorative paw prints everywhere
- UI elements that look impressive but do not help the visitor

### Prefer
- natural spacing
- clear hierarchy
- simple layouts
- realistic imagery
- subtle borders/shadows
- consistent alignment
- familiar navigation patterns
- readable text
- restrained animation
- clear CTAs

## 3. Color System
Use a small controlled palette.

### Primary
A muted green/teal family representing care, trust and wellness.

### Background
Warm white/off-white for the main page background.

### Accent
One restrained warm accent for important highlights and selected actions.

### Text
Dark charcoal rather than pure black for normal text.

### Utility
Standard success, warning and error colors should only appear when communicating status.

Exact color values will be finalized before implementation and then reused consistently.

## 4. Typography
Use a readable modern typeface with a clear hierarchy.

Recommended hierarchy:
- H1: strong page heading
- H2: section heading
- H3: subsection/card heading
- Body: comfortable reading size and line height
- Small text: supporting information only

Avoid using many different fonts.

## 5. Layout
Use a consistent content width and spacing system.

Typical page structure:

```text
Header
Hero / Page introduction
Main content sections
Relevant CTA
Footer
```

Not every page needs a hero banner or identical section structure.

## 6. Navigation
The navigation should be simple and familiar.

Primary links should include the most important pages without overcrowding the header.

The appointment CTA may receive visual emphasis, but it should still look like a normal business website button.

## 7. Buttons
Buttons should:
- have clear labels
- have consistent sizing
- use the primary brand color for primary actions
- use neutral/outline treatment for secondary actions
- have subtle hover/focus states

Avoid excessive button styles.

## 8. Cards
Cards should be used only when content naturally belongs together.

Good uses:
- services
- team members
- blog posts
- structured information

Not every paragraph or section should be placed inside a card.

## 9. Images
Images should look realistic and relevant to pet care.

Use:
- dogs/cats/pets in natural settings
- grooming/care situations
- professional-looking team imagery
- clean facility/service imagery where useful

Avoid excessive stock-photo repetition and decorative images that have no informational purpose.

All meaningful images should have useful alt text.

## 10. Forms
Forms should be:
- simple
- clearly labeled
- easy to scan
- keyboard accessible
- responsive
- validated

Error and success messages should be clear and close to the relevant field/action.

## 11. Responsiveness
The website must work on:
- desktop
- tablet
- mobile

Do not design desktop first and treat mobile as an afterthought.

## 12. Accessibility
Use:
- semantic HTML
- visible focus states
- readable contrast
- proper form labels
- descriptive alt text
- logical heading order
- keyboard-friendly controls

## 13. Motion
Animations should be subtle and purposeful.

Allowed examples:
- button hover
- navigation transition
- small fade/slide when useful

Avoid:
- constant floating animations
- excessive parallax
- distracting page transitions
- animations that make the site feel like a template demo

## 14. Human-Designed Rule
When deciding whether to add a visual element, ask:

> Would a real local business website designer add this because it improves usability or brand communication?

If the answer is no, leave it out.
